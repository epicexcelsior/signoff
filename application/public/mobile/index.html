Prepare the phone

  1. Build the debug APK with npm --prefix application/mobile run build.
  2. Inspect the USB plan with npm --prefix application/mobile run usb:plan -- EXPLICIT_ADB_SERIAL 4022.
  3. After device-operation authorization, install the APK and forward the selected coordinator port.
  4. Transfer the phone's public key through a trusted channel and enroll it before approving a work order.
  5. Start a capture attempt, then load its original request in Phone witness.

The lane README contains exact setup commands, recovery rules, and the signed-envelope interface.

What the signature establishes

A valid envelope binds an enrolled phone key, one work order, one request, a capture time, and an image digest. Camera origin and installation truth remain separate checks.

An interrupted request stays consumed. Start a new coordinator attempt after permission denial, expiry, camera failure, pause, or changed geometry.

No wallet or chain integration exists in this companion. No fixture establishes physical installation or payment settlement.
